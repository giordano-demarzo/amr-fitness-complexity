# Antimicrobial resistance through the lens of Economic Complexity

Code, data, and manuscript for representing antimicrobial-resistance (AMR)
surveillance as a bipartite pathogen–antibiotic network and analysing it with
Fitness–Complexity / block-nestedness tools from Economic Complexity.

**One script regenerates every data file and every figure in the paper from a
single input table.**

## Repository layout

```
reproduce_paper.py         # the whole pipeline: input CSV -> data + figures
requirements.txt

data/reference/            # external reference labels (with provenance)
  SOURCES.md               #   where every dataset comes from — read this first
  who_aware_classification_2023.xlsx   # verbatim WHO download
  who_aware_classification_2023.csv    # 255 antibiotics extracted from it
  atlas_antibiotic_aware_map.csv       # 43 ATLAS antibiotics -> AWaRe tier (used by the pipeline)
  eskape_pathogens.csv                 # ESKAPEE priority-pathogen labels

results/
  temporal_diagnostics/
    pathogen_year_antibiotic_summary_minN_30.csv   # ← THE INPUT (see below)
  analysis/                # generated outputs (committed for convenience)
    clean_prediction.csv                 # Fig 4 rolling-origin candidates
    contagion_hubs.csv                   # Fig 4 per-antibiotic AUC
    nestedness_stats.csv                 # Fig 2 observed vs null nestedness
    validation_stats.csv                 # the Spearman rho's / ESKAPEE medians quoted in the paper
    antibiotic_complexity_validation.csv # per-antibiotic complexity vs AWaRe

paper/
  amr_complexity.tex       # manuscript source
  amr_complexity.pdf       # compiled manuscript
  figures/                 # fig1..fig5 (.pdf and .png), regenerated by the script
```

## The data

- **Input (the only thing the pipeline reads):**
  `results/temporal_diagnostics/pathogen_year_antibiotic_summary_minN_30.csv` —
  species × year × antibiotic counts of susceptible / intermediate / resistant
  isolates (394 species, 43 antibiotics, 2004–2024, cells with `n_tested ≥ 30`).
  Aggregated from the **Pfizer ATLAS** surveillance programme distributed through
  the **Vivli** platform.
- **Reference labels** used only for external validation (Fig 3) and network
  colouring (Fig 4): the **WHO AWaRe 2023** antibiotic classification and the
  **ESKAPEE** priority-pathogen list.

Full provenance, citations, download URLs, and the two corrections applied to the
AWaRe labels are documented in [`data/reference/SOURCES.md`](data/reference/SOURCES.md).

> Note: the raw isolate-level ATLAS/Vivli download is **not** redistributed here
> (it is governed by the Vivli data-use agreement). The aggregated count table
> above is the substrate for all analyses.

## Reproduce everything

```bash
pip install -r requirements.txt

# regenerate all data files and all figures in place
python reproduce_paper.py

# options
python reproduce_paper.py --permutations 0        # skip the slow significance null (figures unaffected)
python reproduce_paper.py --outdir /tmp/run        # write outputs elsewhere
python reproduce_paper.py --input path/to/other.csv
```

The pipeline is deterministic (fixed random seeds), so a re-run reproduces the
committed CSVs and figures bit-for-bit.

### Rebuild the manuscript PDF

```bash
cd paper
latexmk -pdf amr_complexity.tex
```

## Pipeline stages (inside `reproduce_paper.py`)

1. **Prediction** — leakage-free rolling-origin back-test of the co-resistance
   exposure score → `clean_prediction.csv`, `contagion_hubs.csv` (Fig 4).
2. **Structure** — RCA binarization, spectral co-clustering, observed vs
   degree-preserving-null nestedness → `nestedness_stats.csv` (Figs 1, 2).
3. **Validation** — Fitness–Complexity within blocks vs WHO AWaRe / ESKAPEE →
   `validation_stats.csv` (Fig 3).
4. **Figures** — renders `fig1`–`fig5` (`.pdf` + `.png`).
